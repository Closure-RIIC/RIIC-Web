## 发现与处理

| 问题 | 复现 | 修复 |
| --- | --- | --- |
| 登录共享限流桶 | 6 个不同 IP 经终末地代理后，后 3 个被认证库限流 | 认证库明确读取受信入口覆盖的 X-Real-IP；未信任代理时不接受外部转发头 |
| 静态文件无法缓存 | 两次访问均传输同样的 27 个同源资源，缓存命中为零 | public 模式下带 hash 的 assets 缓存一年，图片缓存一小时；页面、API、错误、带 Set-Cookie 的响应和管理员预览仍不缓存 |
| 同步缓存满后失去合并 | 100 条缓存时，同一身份 20 次同步触发 20 次实际读取 | 优先淘汰已完成缓存，保留所有进行中请求的合并；全忙时拒绝新身份，不绕过容量限制 |
| 同步上游无并发上限 | 隔离测试中 300 个不同身份触发 300 次同时读取 | 每个服务进程最多 8 个会话读取（含角色查询和凭据接入）；无无限等待队列，超额返回现有 429 错误；凭据刷新也纳入合并，所有并行读取结束后才释放槽位 |
| 模拟回放阻塞主线程 | 30 工位、96h/10s、4 倍 CPU 降速，最长任务约 10.6s，堆约 98MB | 完整计算及跳转进入独立 Worker；计算中可取消；输入变化或离开时终止；失败可重试；曲线传输前压缩，统计和心情极值仍从完整历史计算；日志每页 50 条 |

## 发布注意事项

共享认证与森空岛后端运行在共享服务中，发布必须覆盖该消费者以及终末地应用。只发布终末地前端不能修复登录和上游并发问题。

生产公开入口的 location / 应透传应用 Cache-Control/Vary，配置参考 deploy/endfield-public.nginx.conf.example；保留私有 Skland 路径的 no-store 和 Origin 校验。应用部署完成后再调整入口，备份精确配置文件，执行 nginx -t 成功后 reload。不要把公开缓存配置应用到管理员预览入口。

并发额度是每进程的会话读取上限，每次同步内部仍有最多三个并行 API 读取。当前 SDK 的请求超时继续生效；即便浏览器断开，进行中的共享请求也占用槽位直到实际结束，避免提前释放造成并发失控。多副本扩容前应评估共享上游 IP 额度和分布式限流。

本地页面吞吐和模拟上游测试不能证明生产账号数据库或森空岛服务的容量。上线后应观察 429/5xx、上游时延、进程内存与事件循环延迟；不将本次结果解读为无限并发保证。
