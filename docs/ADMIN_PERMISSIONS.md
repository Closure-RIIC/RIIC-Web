# 管理员权限

后台采用超级管理员、普通管理员和审阅人的固定角色分级。实现基于已包含 PR #780 邀请活动和 PR #788 注册邀请码更新的 develop；Agent 会话存储是默认关闭、需显式启用的原型。

## 权限来源与调整

超级管理员由服务端环境变量 `BETTER_AUTH_ADMIN_USER_IDS` 控制，内容为逗号分隔的既有用户 ID。解析入口 `packages/platform-server/src/auth/config.ts`，判定入口 `admin-access.ts`。名单优先于数据库 role；数据库的 `admin` 只授予普通管理员。网页可由超级管理员授予/撤销 `admin` 或 `reviewer`，不能修改服务器名单，也不能通过请求字段或数据库 `super_admin` 字符串获得超级管理员权限。

调整正式名单应在实际部署服务的环境配置中增删 ID，并重启所有使用该认证配置的进程/副本。`.env.example` 只提供格式，本机 `.env.local` 不控制远端。代码没有说明实际部署者把环境值存在哪个文件、容器或密钥服务，本次未读取或更改正式名单。

移出名单即失去超级管理员资格；如果数据库 role 仍为 `admin`，账号仍是普通管理员。如需完全撤销后台权限，还要由另一名超级管理员撤销数据库后台角色。不要同时移除所有可用的服务器名单账号。超级管理员网站身份不授予 SSH、数据库、备份或主机权限。

共享鉴权每次读取当前数据库 role/banned，拒绝不存在、封禁和代登录账号，不信任 Session 内的旧角色。Better Auth 原生 `/api/auth/admin/*` 继续统一 404；其原生角色、代登录、密码及删用户功能不会绕过网站管理入口。

## 后台入口

`/admin` 侧栏直接提供“权限管理”（`/admin/permissions`）和“会话导出”（`/admin/agent-archive`）。两个入口及页面搜索结果仅超级管理员可见；直接访问页面仍经服务端验证。

权限管理页通过仅超级管理员可调用的 `GET /api/admin/permissions` 展示当前服务器完整名单，不使用普通用户列表的最近 100 条来推算。只返回名单内账号的 ID、名称、邮箱和封禁状态；配置中不存在的账号会明确标记。页面可以搜索账号并授予/撤销普通管理员、审阅人角色，沿用已有角色确认和服务端事务检查。此页面不能新增/移除超级管理员；名单调整仍通过服务器环境配置。

后台角色授予、改任和撤销统一在权限管理页操作。用户管理页只读展示角色，保留账号查询、封禁/解封及登录 Session 管理，不再提供重复的角色授权按钮。角色对应的能力由服务端固定规则决定，两页读取同一账号角色；权限管理不提供逐项功能授权，也不重复计费或会话导出的业务操作。

管理员和审阅人是同一账号角色字段中的互斥值，改任会替换原角色，撤销后恢复为普通用户。专门的角色变更审计尚未实现，不能将归档或计费的审计记录视为后台授权变更记录。

本地隔离演示：设置 `RIIC_TEST_ENV_DIR` 指向本地连接配置目录后运行 `npm run dev:agent-conversations`，默认 `http://127.0.0.1:5186/admin/permissions` 和 `/admin/agent-archive`。只展示临时库中的合成账号与对话，关闭演示后清理临时库。主目录服务（如 5174）仅在加载本工作区代码后才有这些入口。

## 已实现的边界

| 能力 | 普通管理员 | 超级管理员 |
| --- | --- | --- |
| 用户列表及普通用户管理 | 允许 | 允许 |
| 封禁/解封、查看/撤销后台角色账号的 Session | 拒绝 | 允许；禁止封禁自己 |
| 授予/撤销 admin、reviewer | 拒绝 | 允许；服务器名单账号的角色受保护 |
| 钱包、积分流水、订单、对账、补发/扣回/退款 | 允许 | 允许 |
| 兑换码发放和日常业务 | 允许 | 允许 |
| 自己的归档查看/删除 | 允许；普通用户也允许 | 允许 |
| 任意范围的会话导出、跨用户归档查询 | 拒绝 | 允许并记归档审计 |
| 全站计费汇总、月度统计、调用/模型成本明细 | 拒绝 | 允许 |
| 全局费率、网关/过滤/资源策略及发布 | 拒绝 | 允许 |
| PR #780 邀请拉新活动的查看、开启和暂停 | 拒绝 | 允许；保留原审计/幂等/并发版本检查 |
| 全站账务审计查看 | 拒绝 | 允许 |

计费 API 使用日常业务白名单：GET `wallets/ledger/orders/reviews`，POST `adjust/review`，另有仅返回自身能力的 GET `access`；兑换码继续使用独立管理员接口。其他 section 默认要求超级管理员，避免新增入口意外放行。页面在读取能力前不预取汇总，普通管理员只显示日常标签；超级管理员页面的服务端 loader 同时鉴权。

用户角色变更与封禁/撤销操作在同一事务按用户 ID 顺序锁定操作者和目标，重读当前权限，避免目标在权限检查之后升为管理员仍被普通管理员操作。读取 Session 同样检查目标层级。

网页的“用户 Session”指登录设备会话，不是 Agent 对话正文。本文不引入发放预算、审批流、批量永久删除、留存期限修改或审计删除功能。

## 月度统计口径

`GET /api/admin/billing?section=monthly` 默认最近 12 个北京时间自然月，结束于请求时刻；支持 `from/to`，起点包含、终点不包含，跨度最多 366 天，空月补零。页面按北京时间日期查询，结束日期包含整天。

- 问答轮数、积分：`agent_usage.created_at` 所属月份，重试按已有 usage 记录分别统计。
- 收款、支付订单：仅 `billing_order.status=paid`，按 `paid_at` 所属月份，不按订单创建日。
- 已知模型成本：旧 usage 汇总与新 `agent_model_call` 分开计入，避免 billingVersion 4/5 及存在调用记录的 usage 重复累计；新调用按自身 `created_at` 归月，包括失败运行产生的已知成本。
- 未知成本：展示未知运行及调用数；waived 调用不列未知。金额/积分由 PostgreSQL numeric 求和后按十进制字符串返回，API 保留精度。

这是一份运营用量和成本报表。积分扣费、支付入账和调用成本的发生时间不同；它不能直接当作财务利润表。跨月调用可使同一运行出现在多个成本月份。

## 归档与验证

存储、启用、服务端导出到本机的路径和审计见 [Agent 会话归档](AGENT_CONVERSATION_STORAGE.md)。导出开始及每 200 条重新验证账号、名单和有效 Session；撤权在下一批生效，已收到的内容不能撤回。

可复跑的本地检查：`test:admin-permissions`（隔离数据库及真实签名登录 Session）、`test:agent-conversations`（存储/失败/导出/越权）、`test:billing-monthly`（统计月界及精度）、`test:super-admin:browser`（四角色页面/API和预取边界）。测试使用随机 localhost `*_test` 库并清理，不创建密码或调用模型。`RIIC_TEST_ENV_DIR` 可指定本地连接配置所在目录，不输出连接值。

这些功能测试使用隔离环境和合成数据，不能证明远端部署、生产容量、真实支付或供应商账单正确。发布前仍须按目标分支的当前工作流完成适用门禁；具体候选版本的结果应记录在对应 PR 的验证说明中。
