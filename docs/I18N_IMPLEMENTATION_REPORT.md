# 两站三语国际化实施记录

实施日期：2026-10-29。分支：`feat/x18n-trilingual-20261029`。基线：`7cd2d414ab737720aec63117d0edf935f4ce4ad9`，与规划时 main `3945dfb62f976f8d64ea27d1aaca4cd7fb144079` 的代码树一致。改动位于独立工作树。本文记录本地实施证据，发布状态以对应 PR、GitHub Actions 和两站各环境的部署记录为准。

## 已实现

- 两站与共享账号、导航、控件采用 `zh-CN`、台湾繁体 `zh-TW`、`en`。默认始终简体；兼容旧 cookie/localStorage，站点切换使用一次性 `ui_locale`。
- 保留 `use-intl`。根、路由及延迟加载弹窗按语言加载消息；SSR 与客户端共享语言快照。语言切换预加载后统一提交，失败保留现状并可重试。
- 方舟简体复用规范游戏资料，避免重复序列化中文游戏词典；生成数据和校验仍保留。精确 SSR 消息 JSON：基线全量 139,700 字节；当前首页 46,009、手动页 40,494、技能页 48,716 字节。
- 两站复用方舟已有的流式 gzip 实现。终末地原先不压缩动态 HTML，新增 SSR 词条导致首轮传输量回退；共享工具在保留权限、Cookie 和私有缓存规则的前提下解决这部分开销。
- x18n CLI/builtins 固定为 0.1.2，接入编辑器推荐、本地管理命令和既有 CI 静态检查。ICU、参数、富文本标签、结构化记录和动态键均检查；不关闭整类检查。
- 自定义扫描器跟踪词法作用域、ref、带类型的翻译函数参数及有限动态来源。源码生成的独立引用清单解决 x18n 对同一范围多键引用的去重问题。清理 229 个已审核的旧词条，保留迁移及清理记录。
- 生成器覆盖 Vite 功能别名，资源索引用共享名称表和编号压缩；非 UI 测试验证压缩前后的每个资源集合一致。开发模式只对客户端生成的 JSON 加载器移除导入属性，以兼容 Vite 将 JSON 转为 JavaScript 的行为。
- 修复语言切换触发重新取数/恢复草稿的依赖关系；保留排班、Mower、干员名单、任务身份和用户输入。游戏/MAA/Mower 的规范标识和用户自定义文字不改写。
- 排班、帮助、管理、账号、报告、导出和异常显示进入三语资源；新公告支持 `tw`，历史无繁体的公告保留原文。
- 发布前沿用既有用例补齐：手机技能详情、森空岛及管理指标显式传递当前语言；弹窗关闭按钮使用共享三语标签；职业编号保留原有契约；服务端专精工具独立加载规范中文词条，不依赖先访问某个页面。

维护入口和术语表见 [I18N.md](I18N.md)。

## 性能与运行时选择

完整中位数/p95、测量范围和复测证据见 [I18N_PERFORMANCE.md](I18N_PERFORMANCE.md) 与 [机器可读汇总](i18n-performance-summary.json)。简体桌面首页/手动页/技能页的 HTML、JS、CSS 冷加载传输量，方舟分别减少 9.0%、6.8%、5.0%；终末地分别减少 0.1%、12.6%、18.7%。图片、字体及业务 API 不包含在该指标内。

性能采样后还修正了上述语言参数、弹窗标签、职业常量及服务端工具词条初始化；资源拆分与 HTML 压缩策略保持一致。表格记录的是采样构建，最终修订另以针对性功能回归和包体积门槛验证，不声称对修订后的全部页面重新执行了完整性能矩阵。

耗时没有全部改善：方舟复测部分 hydration 增加约 19–101 ms、干员流程增加约 64–105 ms；终末地部分 hydration 增加约 14–70 ms，英文手机缓存干员弹窗增加约 159 ms。CPU 诊断显示缓存弹窗的 JavaScript、样式和布局存在额外开销，主要采样落在名单/账号组件及滚动容器测量。新增当前语言 SSR 资料也增加服务器组织和序列化工作；尚未作服务端逐函数 CPU 归因，不能把全部增幅断言为翻译解析或采样噪声。保留这些成本记录，不以包体积下降宣称所有交互更快。

测量使用同一基线代码、相同生产开关、本地独立服务和 Chromium；匿名默认页面每组至少 10 次。内联 bootstrap 字节是序列化数据代理，不是单独消息 JSON 字节。计时期间没有并行构建或功能测试，管理员开发服务器不参与计时。

隔离 Paraglide 样例使用 2.29.3、ICU 插件 1.3.4 与 13 条真实消息：Paraglide 三语入口 gzip 5,740 字节；use-intl 入口 14,578 字节，加共享 chunk 361 字节、当前语言 chunk 715–877 字节。它只说明该样例的打包差异，没有完成整页 SSR、富文本和状态保留适配，不能据此宣称全站收益或满足迁移门槛。本批继续使用 use-intl。
