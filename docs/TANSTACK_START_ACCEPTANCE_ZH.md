# TanStack Start 迁移验收

基线为线上提交 `d31a6ae7c7b0b21d24b696aca9a14dda513d84a0`，生产发布分支为 `release/tanstack-start-20261014`，已同步 main 的后续维护改动；开发环境另从 develop 移植。此次覆盖原有 40 个页面入口、68 个 API 入口和构建、打包、部署工作流。原工作区未覆盖。生产 PR #510、开发 PR #511 的 CI 与部署记录为发布状态依据。

## 打开预览

本机访问 **http://127.0.0.1:5178/**。这是独立生产构建产物，构建标识为 `d31a6ae-tanstack-generation`，使用新建的本地隔离 PostgreSQL 数据库。不要用旧的 5177 预览验收本次迁移。

测试账号分为普通用户、reviewer、admin，凭据见任务交付消息。建议先用无痕窗口测试未登录状态，再分别登录不同角色。测试数据可随本地临时数据库停止而丢失，不要在此保存正式数据。

预览期间保持 Docker Desktop 和 `riic-start-d31a6ae-test` 容器运行。当前独立产物已实测三个角色的登录、会话、后台 API 权限及退出。为开放森空岛，运行时使用 `APP_DEPLOYMENT_ENV=development`、`SKLAND_FEATURE_ENABLED=1` 和独立随机会话密钥；仅绑定本机 127.0.0.1，并通过既有 `SKLAND_ALLOW_INSECURE_HTTP=1` 支持本机 HTTP。正式部署仍须使用 production 和 HTTPS，不沿用该 HTTP 例外。

森空岛扫码和凭据登录已开放：先登录网站测试账号，再进入 `/skland` 阅读并确认授权条款，自行扫码或输入凭据。会话接口、功能可用状态和授权确认门禁已验证；实际森空岛授权与同步仍待用户验证。Windows 本地求解器已经接通，独立产物的健康检查和示例排班真实计算均通过；个人 Box 仍待用户验收。邮件服务、模型提供方和支付服务尚未配置。结果生成点阵线框动画已移除，保留普通加载骨架屏。

## 手动测试清单（待用户验证）

每项完成后勾选；发现问题时记录页面 URL、账号角色、操作、预期与实际结果。

- [ ] **1. 首页与页面版本**：打开 `/`，强制刷新，再从页脚打开 `/wishes`。应保留线上新版布局、入口和许愿表单，没有旧版页面回退。
- [ ] **2. 语言与导航**：切换英文，依次进入 `/training`、`/skills`，刷新并使用浏览器后退、前进。语言、标题、选中导航和 URL 应一致。
- [ ] **3. 排班与工具**：打开 `/manual`、`/mower`、`/mastery`、`/recruitment`，编辑表单、切换筛选；Mower 切换计划后导出。应保留已有交互，导出只包含所选计划，页面不出现异常横向溢出。实际求解另行验收。
- [ ] **4. 森空岛、库存与抽卡**：打开 `/skland`、其库存/基建页签、`/inventory`、`/gacha`。检查未登录提示、页签、筛选及刷新后的 URL。真实授权、账号切换和同步须在服务配置完成后验证。
- [ ] **5. 设置与账号健康**：打开 `/settings`，改变语言和显示选项后刷新，确认设置保留；打开 `/account-health`，确认会话状态和入口正确。
- [ ] **6. 帮助深链接**：打开 `/help/beginner` 和导入指南，点击包含查询参数的步骤链接，再前进、后退、刷新。应定位到对应步骤，参数不丢失。
- [ ] **7. 普通用户登录**：在 `/account` 登录普通账号，刷新后应仍登录；退出后直接访问后台 URL，不应看到受保护内容。
- [ ] **8. Reviewer 权限**：登录 reviewer，访问 `/admin`、`/admin/issues`、`/admin/quality`、`/admin/wishes`；应能访问审核范围。访问 `/admin/users`、`/admin/billing`、`/admin/agent` 应被拒绝。
- [ ] **9. 管理员后台**：登录 admin，打开用户、计费和 Agent 管理页，刷新、切换菜单、滚动长列表并打开弹窗。页面应正常加载，弹窗关闭后滚动恢复。
- [ ] **10. Agent 与计费**：以 admin 打开 `/agent`、`/billing`，检查页面和权限提示。实际模型响应、流式输出、充值及对账留待配置服务后验收。
- [ ] **11. 毛绒画廊**：打开 `/plush`，拖动或按压角色；在桌面和 390px 手机宽度检查交互与布局。
- [ ] **12. 滚动条**：在长页面、侧栏、弹窗和下拉框内滚动、拖动滚动条、使用键盘；同时检查深色和减少动态效果模式。滚动条不应宽度为零，弹窗不应导致背景滚动失控。
- [ ] **13. 手机与法律页面**：390px 宽度打开 `/privacy`、`/terms`，切换语言。正文、图片、链接、标题应完整可读，没有横向溢出。
- [ ] **14. 错误与退出状态**：打开不存在的 URL，应显示 404；退出后重新访问受保护 URL，应被拒绝，不应残留上一个用户的数据。
- [ ] **15. 排班结果展示**：生成排班后检查顶部基建方案及一图流卡片，应直接显示；切换列表、一图流、班次、原方案与练度调整后方案，并导出图片，应无点阵线框重播、卡片闪烁或内容缺失。

受影响 UI：所有上述页面及公共导航、国际化、登录状态、图片/字体加载、页面滚动条。完整实现与自动验证记录见 [迁移报告](./TANSTACK_START_MIGRATION.md)。

本地自动验证：生产构建、TypeScript、ESLint、资源和产物检查通过；862 项非 UI 业务/API 测试通过（3 项可选用例跳过），22 项隔离数据库集成测试通过，最终 29 项生产产物 E2E 全部通过。自动测试不代替以上手动验收。

## 什么情况下可以发布

以下条件仍须完成，不能用本地构建成功代替：

- [ ] 上面的手动 UI 清单通过，并在配置齐全的环境中验证求解器、森空岛、邮件、Agent 和支付流程。
- [ ] 必需远端 CI 和受支持浏览器检查通过。此次遵照仓库规则未运行 UI 单元测试，也没有移除既有 CI 检查。
- [ ] 线上部署 helper 安装已通过检查的 contract **7**，支持 `.output` 布局、三个 worker、运行时环境加载及旧 Next 产物回滚；helper 在独立仓库审查。
- [ ] 在真实反向代理/CDN 后检查私有 HTML 的 `no-store`、Cookie、压缩和流式响应，并验证切换及回滚后的会话兼容性。
- [ ] 审查并提交本工作树的实际 diff，再按现有发布策略执行获授权的发布。

当前发布配置显式启用森空岛，其客户端产物检查通过。可选的“关闭森空岛”构建仍会被严格文本扫描中的既有业务/帮助文案拦截；未放宽该检查，不能将它标记为可发布配置。Nitro Node 适配器当前锁定的是 beta 版本，也须随发布验证记录保留。
