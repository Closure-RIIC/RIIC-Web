# Agent 资源管理与回答边界

## 职责

- `/admin/agent` 管理人格、共享系统提示词、知识库正文/索引/规则和 Skills。资源保存在私有数据库的版本快照中，不提交到公开仓库。
- RIIC Agent 为每次请求读取一次已发布版本，将同一快照传给人格解析、提示词组装、知识检索和任务指引工具；权限、工具执行、会话与钱包仍由 RIIC 控制。
- Magpie 处理模型路由、故障切换、网关过滤和用量采集。模型切换不会改变资源版本。不要同时在 Magpie 开启覆盖应用 Prompt 的 `system-prompt.override`。

## 首次启用

1. 按项目发布流程执行迁移 `0024_agent_resources.sql`。它只扩展配置类型约束，没有生产知识数据回填。
2. 管理员进入 `/admin/agent`，选择“导入服务器资源”。服务端只读取现有 `AGENT_KB_DIR`、默认人格与内置人格配置，浏览器不能指定文件路径。
3. 核对默认人格、已启用人格、系统提示词、知识索引和任务指引，填写变更原因并保存草稿。
4. 打开草稿检查后，选择“发布选中草稿”。未发布时仍用原服务器文件。发布后，下一次请求使用该完整快照；正在运行的请求继续使用开始时的版本。
5. 需要撤销时，在历史版本选择“恢复并发布”。回滚创建新版本，不改写旧版本。所有草稿、发布、回滚都有管理员审计；并发发布使用当前版本校验，过期操作会被拒绝。

资源是环境内独立发布的；development 的草稿/发布不会自动写入 production。导入读取当前文件，不安装、拉取或覆盖外部知识仓库。知识源更新后需重新导入、检查和发布；已有快照可在后台直接编辑。索引缺失引用、路径越界、重复 ID、空的已启用资源或无效 JSON 会拒绝保存。资源总大小上限 8 MB，正文单文件上限 200000 字符。

启用前后用户上传的人格仍然只作用于该请求；共享中文、格式、事实核实规则由服务端追加，不能在后台删除。仅启用的内置人格出现在前台；关闭的 Skills 不会出现在提示词中，直接调用也会被拒绝。

## 历史消息与输出

此前网关把浏览器 `tool-*` 快照序列化成 assistant 的普通文本，可能引起 JSON 回显、历史内容失真及英文过程旁白。现改为：

- 浏览器历史只保留用户输入、合规附件和工具步骤之后的最终回答；不接收 system 消息，不重放历史工具执行状态、结果及 reasoning。
- 同一次请求内真实工具结果仍由 AI SDK 以 tool 消息送回模型。需要历史精确数据时重新查询；不会把浏览器伪造结果提升为服务端事实。
- 模型每个步骤的文本先暂存，若该步骤调用工具，文本不进入用户回答；工具进度仍实时可见。最终步骤完成后，检查协议标记并释放正文。这会推迟正文的首次显示，避免把尚未确定用途的过程文字展示给用户。
- 模型 reasoning 不发送到前端。Prompt 默认要求简体中文，用户明确要求其他语言时允许切换；语言规范属于模型指令，不是确定性的翻译器。
- 跨分片的内部工具 JSON 和角色分隔符会触发流内错误，原文不交付；旧本地历史的异常正文显示重新提问提示，不删除用户历史。
- 仅交付经过检查的正文才标记文字已交付。失败且未交付的纯对话不扣用户积分，已测用量仍记录；已成功的收费业务工具按原计费规则结算。

`X-Agent-Resource-Version` 返回此次资源版本；未启用版本管理时为 `configured`。它不包含人格内容或文件路径。

## 验证

- `npm run test:agent-resources`：历史净化、真实 AI SDK 多步知识工具、协议分片、资源校验、API 权限。
- `npm run test:agent-resources-integration`：仅用于 `AUTH_INTEGRATION_DATABASE_URL` 指向的隔离 `_test` 数据库；覆盖原子发布、并发冲突、请求快照和审计回滚。
- `npm run test:agent-billing-integration`：包含上述数据库测试和网关输出被拦截后的计费验证。
- `npm run test:agent-billing:e2e`：Node.js + Playwright 验证后台编辑、发布、回滚、移动屏幕与中英文。

人工验收：中文技能问答及追问不出现英文旁白或内部 JSON；切换人格保持语气；发布知识修订后新请求采用新版本；禁用指引后不可加载；恢复历史版本后行为恢复。真实上游模型的中文遵循与知识回答质量需要在线问答验收，模拟模型测试只验证协议和工具链。
