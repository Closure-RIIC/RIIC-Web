# 终末地步进模拟

入口为终末地侧边栏“手动排班”中的“模拟回放”（英文 `Simulation replay`），路由 `/manual?view=simulation`。旧 `/step` 自动跳转至此，沿用终末地的管理员访问限制。

手动排班和自动排班均通过“编辑名单”打开同一个名单弹窗。自动排班提供“森空岛同步”入口；同步后会在本地工作区保存独立的 `sklandRoster` 名单备份，不包含凭据或完整角色详情。手动增删、修改精英化或技能，以及 [PR #596](https://github.com/Closure-RIIC/RIIC-Web/pull/596) 的“仅升级已拥有”和“添加全员并全精4”操作都不会覆盖备份。“恢复森空岛数据”恢复最近同步的名单、精英化和技能，保留设施与生产设置、有效的手动工位，清空已移出名单的工位。备份随刷新保留；没有完整同步记录时禁用恢复。部分同步只能更新同来源的真实备份，不能把手动配置当成完整森空岛名单；切换网站会话或退出后清除备份，重新同步后可再次恢复。

人员、设施和换班时间只在手动排班中编辑一份。关闭干员选择、名单或设施弹窗、回到编辑主面板后，停顿 300ms 自动计算长期产出与心情闭环；直接修改换班时间也会自动计算。原设施卡片一直保留加成和产出区域，首次显示占位，后续计算时保留上次数字并显示“计算中…”，详细报告暂不可用。计算完成后，产出、班组加成及全舰汇总使用与明日方舟共用的 `AnimatedNumber` / Calligraph 动画过渡至新值，尊重系统减少动态效果偏好。弹窗打开或切换回放时取消计算，回到主面板再计算最新输入，旧任务不能覆盖新结果。评估支持未排满的班组和空班，空班按 A/B 时段换班，不转换为单班循环。自动评估使用独立 Worker，不覆盖首页生成的方案，也不弹出完成通知。“模拟回放”仍需手动开始，直接读取同一份排班，查看 24–96 小时内的心情、换班、助力与产出变化。需要使用自动方案时，沿用“使用当前双班结果”操作。

初始心情、起始工作状态、助力目标与时间、起点、时长、采样和播放速度是模拟专属参数，不修改手动排班或长期评估。修改人员、设施、技能或换班时间会停止并重置旧回放，保留模拟参数；切换到评估视图也会停止播放。模拟参数以 v2 格式保存于原有本地存储键，读取 v1 时只迁移心情、工作状态及助力，忽略旧舱室启用和换班时间，防止覆盖共享配置。站内清空本地数据时也会清除模拟设置。

自动评估的未收敛、独立校验及 Worker 错误统一显示在全局 Live Activity，详细原因分段展示，并提供收起和重试；重试仅重算当前手动排班。修改排班、切换回放或离开页面会移除旧错误提示，不在卡片上方插入错误文本，未通过校验的产出也不会当作有效数字展示。

页面基于 [PR #603](https://github.com/Closure-RIIC/RIIC-Web/pull/603) 的舱室标签、心情 / 产率双图和干员状态卡继续改造。交互参考明日方舟 `components/manual-mood/MoodSimulationPanel.tsx`：编辑 / 回放视图切换、模拟设置弹窗和可拖动时间轴。图表沿用 #603 的 Recharts 实现、阶梯曲线、小时刻度、提示、短线图例和紧凑布局。干员卡片直接控制曲线，默认全部选中；点击卡片切换选中状态，可只选一个或同时选多个，选中卡片显示高亮与勾选标记。切换舱室保留各自的选择。全部取消时心情图区显示选择提示，产率图仍正常显示。干员列表、日志和统计表使用共享 `ScrollArea`，时间轴使用基于 Base UI 的共享 `Slider`。

终末地显示 0–100% 心情，保留自己的换班、助力和产率算法。曲线展示完整模拟时段，横轴为已模拟小时，虚线标记当前回放位置。点击图表或拖动时间轴会暂停播放并按同一事件引擎定位；向后跳转重建初始状态，确保助力和换班不被重复累计。状态卡读取游标处的真实引擎快照，不提前采用未来采样点；生产产率换算为基础产率的百分比展示，中枢恢复加成本来就是百分点，不重复乘 100。事件日志与统计默认折叠。

## 保留的实现

- `apps/endfield/src/components/ManualPage.tsx`、`MoodSimulationPanel.tsx` 与 `Step*.tsx`：共享排班、模拟参数及回放组件；`src/routes/step.tsx` 仅保留兼容跳转。
- `apps/endfield/src/mood-simulation/`：基于 PR #603 的回放控制、舱室双图、状态卡和纯数据展示适配。
- `apps/endfield/src/step/`：事件时间线、工作区数据映射、本地存储和样式。
- `packages/endfield-solver/simulation.*`：复用求解器技能解锁、去重规则和速率常量的数据适配层；不增加第二套技能数据。线索概率技能不计入确定性产量。
- 引擎、工作区适配与求解器数据边界的非 UI 回归测试。

页面使用站内 React / TypeScript 与 TanStack Router，不嵌入独立 HTML 或另一套前端运行时。侧边栏复用现有折叠、选中态和移动抽屉逻辑；排班使用 `FacilityBoard`、`FacilityCard` 与 `OperatorPortrait`，干员选择复用 `RosterPage`、`DialogFrame` 和 Base UI 的焦点管理。标题、分区、按钮、提示、下拉筛选、输入框和日期标签分别复用 `PageTitle`、`Section`、`Action`、`Notice`、`Field`、`Input` 和 `Tabs`。

原独立页面的整套样式已移除。仅保留时间轴、曲线与心情条所需布局，限定在 `.ef-step-page` 下，颜色跟随站内深浅主题。模拟器通过稳定快照更新 React 状态，不在渲染过程中读取可变引用；播放速度不受曲线采样间隔影响。

本地 e2e：在具有独立预览会话的终末地开发服务上运行 `node --experimental-strip-types scripts/test-endfield-manual-simulation.mjs`。可用 `ENDFIELD_E2E_ORIGIN` 指定本机服务、`ENDFIELD_E2E_ENTRY` 指定本机预览登录跳转入口；脚本只接受 localhost / 127.0.0.1，使用独立浏览器上下文和构造的排班数据。

名单同步和恢复可运行 `node --experimental-strip-types scripts/test-endfield-roster-recovery.mjs`，使用相同的本地环境变量。该脚本模拟森空岛接口，验证两个入口、两种全精4范围、刷新恢复、移动端弹窗和会话切换，不访问真实游戏账号。

步进引擎用于指定初始心情、起点和有限时长的过程回放；现有求解器评价器用于搜索及周期收敛后的产量评估。两者用途不同，回放不替代求解器结果校验。已删除独立模拟页的第二套人员编辑、导入和设施设置，避免两份排班相互偏离；保留两种计算入口。

## 从 PR #586 移除的内容

| 内容 | 移除原因 |
| --- | --- |
| 明日方舟新增的独立 `/changelog` 路由及页面 | 与既有 `_workbench.changelog` 指向同一路径，导致路由生成失败；两页均渲染既有 `ChangelogPage`。 |
| 明日方舟新增的账户页面、加载页、`AccountRoute` 和重置密码页面 | 当前账户设置与认证弹窗已承接这些功能，旧书签路由已有重定向；这些文件不参与步进模拟。 |
| `SolverLiveActivity.tsx` | 没有导入者；既有 `WorkspaceLiveActivity` 已统一处理求解、森空岛同步和账户反馈。 |
| `packages/endfield-simulated/` 独立 HTML/JS/CSS 副本 | 原页面已移植至当前 React 路由；旧副本依赖另一套静态路径和 `Dijiang*` 存储键，未接入构建。保留两套页面会重复维护模拟逻辑和样式。 |

原始实现与贡献历史保留在 [PR #586](https://github.com/Closure-RIIC/RIIC-Web/pull/586) 和[固定版本的源目录](https://github.com/Courison/RIIC-Web/tree/b832785397a6b3efee3c34fa46912b1c69f94a0d/packages/endfield-simulated)。
