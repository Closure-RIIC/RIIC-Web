# 排班作业中的干员池

作业文档的 `operators` 保存当前使用的完整干员池，包括未排班和未持有的条目及其练度、潜能、稀有度和持有标记。创建、导入、页面保存、下载和作业码分享均不按排班人员裁剪，文件校验上限为 1000 条及 256 KB。

布局中的回收站使用 `kind: "recycle"`，与其他设施一同保存在作业文件及作业码中；导入后保留两个槽位的位置，包括仅安排第二个槽位的情况。

新建排班的配置范围为 2–4 班；历史单班手动草稿仍可恢复，保留已有排班，不按新建配置的班数下限丢弃。

继承作业时，以作者随作业保存的干员池作为编辑和计算的初始来源。可在“配置 Box 与布局”中上传或粘贴自己的 Box、手动调整，或使用森空岛数据；这些操作替换当前作业副本的干员池并保留排班，已有个人记录的练度优先。新 Box 缺少的已排班人员、菲亚梅塔及其充能目标保留原作业练度，作为 `own: false` 的外部参考供继续调整；充能目标无需排入房间也会保留。旧文件连参考练度也缺失时才补图鉴示例。计算时为这些仍被排班引用的外部人员建立临时可计算条目，保存文件中的持有标记保持原样。

继承副本的当前排班和完整干员池保存在当前浏览器标签页的 `sessionStorage`，刷新后继续使用最新副本，包括已经切换到个人 Box 的状态。点击“返回个人草稿”清除该副本的恢复状态。文件与作业码记录当前编辑所用的干员池；历史文件未包含的作者干员无法恢复，只补齐实际引用人员。
