# MAA 排班文件读写

手动排班与作业图下载共用 `downloadManualMaa`。手动新建排班按当前布局生成 MAA；从 MAA 导入的排班同时保留原文件及编辑器投影，下载时只回写实际编辑的字段，保留未改动的时间段、说明、动作顺序、设施缺省与空数组。

训练室使用 `training`，`operatorsB` 是训练位候选，`operatorsA` 是协助位候选；两个位置独立，空位置不能使另一个位置前移。编辑器显示首选干员并保留其余候选顺序。训练室只导出这两组候选和 `skip`，不写通用 `operators`、`sort` 或 `product`。

回收站使用布局中的 `kind: "recycle"` 和该设施的实际 id，等级沿用现有布局；旧布局没有回收站时，编辑器补充 `recycling_station`。MAA 只输出一间 `recycle`，保留干员编组、候选、跳过及自动填充设置，不写产物。未配置的手动回收站可以省略；导入文件显式给出的空数组通过原始记录保留。

导入后的布局、排班与候选信息在刷新和作业文件读写中一并保留。作业文档允许预设布局已有的回收站，避免新增设施后保存或分享失败。回收站的求解器布局与计算能力由设施协议负责，导入导出层不重新维护一套设施类型。

编辑器为满足最少班次数补出的空班没有原文件来源；下载时忽略未改动的补空班，实际编辑后才将它作为新增计划导出。原文件中的有效计划及其时间选择保持原样。
